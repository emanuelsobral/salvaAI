# Guias do SalvaAI

Use estes guias para cadastrar suas finanças, revisar importações e entender os cálculos do aplicativo.

| Guia | O que você encontra |
|---|---|
| [Finanças](financas.md) | Saldos, caixinhas, compras parceladas, faturas e projeções |
| [Importação de extratos](importacao-extratos.md) | Formatos aceitos, revisão de PDF, OCR e duplicidades |
| [Contas recorrentes](contas-recorrentes.md) | Cadastro, calendário, pagamento e encerramento de recorrências |
| [Agenda de contas](agenda.md) | Visões semanal e mensal, filtros, pagamentos e vínculo com extratos |
| [Edição de recorrências](edicao-recorrencias.md) | Alteração de valor e calendário sem apagar o histórico |
| [Conciliação](conciliacao-extratos.md) | Como vincular despesas importadas aos vencimentos |
| [Contratos](contratos.md) | Cadastro manual, leitura de PDF/OCR e planejamento de parcelas |

O [README principal](../README.md) reúne instalação, configuração do Firebase, testes e publicação. Para usar a extração pelo terminal, consulte o [guia do extrator](../experiments/contracts/README.md).

O SalvaAI registra pagamentos informados por você e não executa operações bancárias. Confira os dados importados antes de confirmar, sobretudo valores, datas, conta de destino e possíveis duplicidades.
